# The Houdiscert Suite
**The Houdiscert Suite** is a web-app suite created by [houdert6](https://github.com/houdert6). It is comprised of three products, all under the domain `houdiscert.com`.

## houdiscert
[houdiscert](https://houdiscert.com) is the first and main product of The Houdiscert Suite. Its name is a portmanteau of "houdert6" and "Discord," because it is a "Discord Clone," meaning it does the same thing [Discord](https://en.wiktionary.org/wiki/debacle) does. It was first suggested in February of 2025 and the domain was later registered in March of the same year. It uses the [React Framework](https://react.dev/) developed by [Meta](https://en.wikipedia.org/wiki/Satan). Its name can be shortened to *hdc* (**h**ou**d**is**c**ert).

[The houdiscert repository](https://github.com/houdiscert/houdiscert)

## Password Manager
[Password Manager](https://pm.houdiscert.com/), also referred to as *Houdiscert Password Manager* or *HDC PM*, is a much more recent product under The Houdiscert Suite. It was created not long after two-factor authentication was added to [houdiscert](#houdiscert) as a way for users to enable two-factor authentication without using any third-party authenticator app and can also be used to store and generate passwords and be used as an authenticator app for third-party sites and applications.

[The Password Manager Repository](https://github.com/houdiscert/password-manager)
> *This is only the backend of Password Manager. The frontend has no remote repository.*

## LynxDC
[LynxDC](https://lynxdc.houdiscert.com/) was a Discord proxy created for a specific user to access Discord on his school-issued device, which had blocked `discord.com` from being accessed. It is now defunct.

> *LynxDC has no remote repository.*
