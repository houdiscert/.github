# Houdiscert
**Houdiscert** is a web-app suite created by [houdert6](https://github.com/houdert6). It is comprised of two projects as of Oct 22, 2026. Here you can read about them. For updates and news on Houdiscert, subscribe to our [RSS Feed](https://raw.githubusercontent.com/houdiscert/.github/refs/heads/main/rss.xml).

## Discert
[Discert](https://houdiscert.com) is the flagship project of The Houdiscert Suite. Its name is a portmanteau of "houdert6" and "Discord." Houdiscert is a chat app mimicking the look and functionality of [Discord](https://discord.com). It was first suggested in February of 2025 and the domain was later registered in March of the same year. It uses the [React Framework](https://react.dev/) developed by [Meta](https://en.wikipedia.org/wiki/Satan). In October 2026 many spam accounts were created on the site, leading account creation via the web page to be disabled. Ever since this, the only way to create an account is by manually emailing houdert6 on [Gmail](mailto:houdert6@gmail.com) or [Protonmail](mailto:houdert6@proton.me).

## Password Manager
[Password Manager](https://pm.houdiscert.com/) is a much more recent project of Houdiscert. It was created not long after two-factor authentication was added to [houdiscert](#houdiscert) as a way for users to enable two-factor authentication without using any third-party authenticator app. It can also be used to store and generate secure passwords and be used as an authenticator app for third-party sites and applications.
